## 2024-05-18 - Negative Caching in Laravel
**Learning:** `Cache::remember` does not cache when a closure throws an exception. In high-traffic scenarios where external API requests are expected to fail frequently (e.g., users testing invalid tracking numbers), this can bypass caching entirely and lead to rate-limit exhaustion.
**Action:** When an external API dependency has expected failure modes, avoid `Cache::remember`. Instead, implement negative caching by manually managing `Cache::get` and `Cache::put`, caching both successful and expected error responses (wrapped in an array) to prevent repeated redundant hits.
